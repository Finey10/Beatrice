PUT YOUR REAL PHOTOS HERE ✦

1. Add your photos to this folder, named like:
     memory-1.jpg, memory-2.jpg, memory-3.jpg …

2. Then open js/config.js and set each memory's:
     image: "images/memory-1.jpg"
     date:  "14 March 2023"
     title: "Our first trip"
     note:  "Optional short message"

Tips
- Portrait photos look best as "tall" tiles, wide photos as "wide"
  tiles — the layout mixes sizes automatically.
- Resize photos to max ~1600px on the long edge before adding them,
  so the site loads fast on her phone.
- Until a photo exists, its tile shows an elegant dashed placeholder
  box telling you exactly which file is missing.
